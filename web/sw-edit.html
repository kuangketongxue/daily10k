这一期要收藏吗？

说明：网站本身是纯静态的，浏览器没有能力直接改仓库文件（也不该把 GitHub 密钥放进网页）。所以「收藏」这个写动作要在本机执行一次命令，之后收藏夹和全文归档会随站点一起发布上线。

未指定日期 等待确认

第 1 步 · 在仓库目录打开终端，执行下面这条命令：

node scripts/favorite.mjs add 2026-11-06

第 2 步 · 提交并推送，让收藏夹上线：

git add web/data && git commit -m "收藏 2026-11-06" && git push

取消收藏把 add 换成 remove 即可。想直接看当前收藏夹，执行 node scripts/favorite.mjs list。

如果你是在手机或别的电脑上打开的这个页面，这台山电脑的命令行不方便用 —— 可以直接在 GitHub 网页上编辑 web/data/favorites.json， 再把对应全文放进 web/data/archive/，效果完全一样。
